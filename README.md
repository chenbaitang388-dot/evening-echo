# 晚风留声 · 完整版 1.0

现代大学校园离线视觉小说。第一人称主角 20 岁，恋爱相关主要角色均为 20—23 岁成年人。包含完整公共篇章、六条人物路线、群像与隐藏篇，结局由相处中的选择决定；游戏不显示好感数值、未发现结局数量或结局好坏评级。

## 开始游玩

可直接使用 Edge / Chrome 打开 **index.html** 游玩。Windows 桌面程序需先使用 desktop/build.ps1 和 WebView2 SDK 编译，随后双击 **EveningEcho.exe** 或 **Start.cmd**。请将游戏保存在具有写入权限的文件夹中。

Windows x64；需要 .NET Framework 4.7.2 或更新版本及 Microsoft Edge WebView2 Runtime。剧情、美术与音乐在本地运行，无需账号、开发服务器、Node 或 Python。系统运行库未包含在压缩包中。主窗口无法启动时，可用 **EveningEcho.Edge.exe** 调用本机 Edge 的独立应用窗口；也可以用 Edge 或 Chrome 打开 index.html。

本版全分支正文约 7.15 万字符。按每分钟 300 字估算，一条人物线约 40—46 分钟，多路线体验更长。这个数值是文本估算，不是人工计时，也不通过强制等待延长游玩。

## 操作与存档

- 点击对白、空格或 Enter：显示全文、继续。
- A：自动阅读；选项出现后停止，由玩家选择。
- Ctrl：按住跳过已读文本，遇到未读内容停止。
- S / L：存档 / 读档；H：历史；F：全屏；Esc：设置或关闭菜单。
- 提供手动槽、自动存档、快存快读及 JSON 导入导出。关闭主窗口时保存当前进度。
- 桌面版存档位于 PlayerData；Edge 备用版位于 PlayerData-Edge。切换启动方式前导出存档，再导入另一种方式。
- 从秋日修订版更新时，路线和选择保留；被改写的当前章节从段首重读。初版旧结构存档不能直接导入。
- 更新或移动文件夹时保留 PlayerData、PlayerData-Edge，也可另存导出的 JSON。不要只复制 EXE。

## 声音与画面

七组程序合成音乐主题，BGM、音效和系统朗读音量独立调整。系统朗读是可关闭的辅助功能，不是角色配音。

六位角色各有独立表情与姿态方向，旁边用对应色系姓名标签标识。新增立绘、背景、CG 和图标由内置图像生成/编辑工具制作并保存在 assets 中。此源码副本只包含游戏素材，不包含制作过程记录。
